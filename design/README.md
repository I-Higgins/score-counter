# design/

Put your Claude Design export here (screens, tokens, component specs, icons, motion, notes).

- It's **reference only**: it isn't served, precached or published.
- Claude Code treats it as the source of truth for visuals (see `CLAUDE.md`).
- Copy the design's tokens into `css/tokens.css` (keep the token names), its icon art into `assets/app/`, and its UI icons into `js/icons.js`.
